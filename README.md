# 小镇专注

> 回到二〇一九年的夏天，给时间留一扇窗，也给自己留一页日记。

《小镇专注》是一款带有叙事色彩的轻量专注应用。它不把专注变成打卡、排名或效率竞赛，而是用窗景、环境声和关系碎片，记录那些原本很容易被忘记的时刻。

故事发生在 **2019 年 6 月的陕西咸阳**：高二下学期，第一次理综合卷刚结束，麦子泛黄，天到八点才黑。你可以做题、帮家里做件事、和谁待一会儿，也可以什么也不做，只是躺下、听雨、让脑子歇一歇。

## 产品特点

- **四种专注对象**：做题、帮家里做件事、和谁待一会儿、什么也不做。
- **灵活的时长**：25 / 45 / 60 分钟预设，或自定义 5–120 分钟。
- **会变化的窗景**：雨过天晴、家属院午后、塬上黄昏、夏夜窗灯，使用 Canvas 实时绘制。
- **可组合的声景**：生成轻音乐、内嵌原声音乐、雨声、风声、夜市、篝火、虫鸣，以及白噪、粉噪、褐噪；支持叠加环境声和音量调节。
- **克制的打断处理**：主动暂停以五分钟为提示；切出页面自动暂停，回来后再继续；刷新可恢复未完成的专注。
- **关系碎片日记**：自然完成专注后，从妈妈、同桌或父亲等视角留下一段小事，不展示效率分数。
- **属于自己的纪念册**：可以补记当下、独立写日记，也可以拍照或从相册选择一张照片。
- **离线可用**：页面、样式、逻辑、Canvas 和音频均在一个 HTML 文件中，无框架、无 CDN、无运行时外部请求。
- **移动端与无障碍适配**：支持手机布局、键盘操作、焦点管理、读屏提示和减少动态效果设置。

## 如何体验

### 获取方式

- **电脑**：下载离线包（国内可达，约 2.7 MB）：<https://cdn.jsdelivr.net/gh/skyelai0111/small-town-focus@main/SmallTownFocus-web.zip>，解压后双击「小镇专注.html」即可，无需安装；macOS、Windows 通用。也可到 [Releases](https://github.com/skyelai0111/small-town-focus/releases) 下载。
- **手机**：在线版入口筹备中（jsDelivr 出于安全策略按纯文本返回网页，暂不能直接在线游玩；国内托管就绪后会更新此节）。
- 国际网络可直接访问：<https://skyelai0111.github.io/small-town-focus/>

### 完整专注流程

1. 首次打开，阅读“回到那个夏天”的序章。
2. 选择今天想把时间给谁，再选择专注时长。
3. 点击“坐下，开始”。
4. 在专注页选择喜欢的窗景、主声景、叠加环境声和音量。
5. 保持页面在当前窗口。需要离开时，可以主动暂停；切出页面也会自动暂停。
6. 倒计时自然结束后，阅读一段关系碎片。
7. 可以补一句自己的话，或留下一张照片，然后翻开“小镇纪念册”。

**提前“起身”不会生成关系碎片。** 如果想直接写一篇自己的日记，不需要先完成专注：从开始页进入日记册，点击“写一页”即可；只留照片、不写字也可以。

### 本地直接打开

双击 `index.html`，使用最新版本的 Chrome、Edge、Firefox 或 Safari 打开即可。无需安装依赖，也无需构建。

### 本地 HTTP 预览

在项目目录运行：

```bash
cd ~/Desktop/game
python3 -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```

如果系统提供的是 `python` 而不是 `python3`，也可以运行：

```bash
python -m http.server 8000
```

停止预览时，在终端按 `Ctrl + C`。

## 发布到 GitHub Pages

这个项目不需要 `package.json` 或构建工具，可以直接作为静态网站发布。

1. 在 GitHub 新建公开仓库，例如 `small-town-focus`。
2. 将 `index.html` 和 `README.md` 上传到仓库根目录。
3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**。
5. 选择 `main` 分支和 `/(root)` 目录并保存。
6. 等待部署完成后，访问：

```text
https://你的用户名.github.io/small-town-focus/
```

以后更新仓库根目录的 `index.html`，Pages 会随之更新。GitHub Pages 在国内不同网络和运营商下的访问速度可能有所差异。

## 数据与隐私

- 日记文字、应用设置和未完成专注保存在浏览器的 **localStorage** 中。
- 照片经过压缩后保存在浏览器的 **IndexedDB** 中，只存在当前设备上。
- 日记显示的故事时间统一为 **2019 年 6 月**；真实时间会另外保存，用于日记排序和事件条件。
- 应用没有账号、服务器或云同步，不会主动上传日记和照片。
- 更换浏览器、设备、域名或访问协议后，原有存档通常不会自动迁移。
- 清除浏览器网站数据可能永久删除纪念册，请谨慎操作。

## 技术说明

- 原生 HTML / CSS / JavaScript
- Canvas 2D 动态窗景与照片压缩
- Web Audio API 程序化声景
- localStorage 持久化文字、设置和专注恢复
- IndexedDB 持久化照片
- Screen Wake Lock API（浏览器支持时防止屏幕休眠）
